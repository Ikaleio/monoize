## 访问仪表盘

在浏览器打开 Monoize 的监听地址，默认是 `http://localhost:8080`。release 构建在同一进程中提供仪表盘、API 和指标。

![仪表盘概览](/images/zh/dashboard.webp)

## 账号与角色

- 安装后注册第一个账号。第一个注册的账号自动成为 `super_admin`。即使公开注册已关闭，此规则仍然生效。
- `super_admin` 可以管理用户、系统设置、Provider 和计费。
- `admin` 账号管理运营资源。
- `user` 账号管理自己的 API 密钥、日志和余额。

## 管理区域

| 区域 | 用途 |
| --- | --- |
| 仪表盘 | 当前登录账号的流量、费用和健康状态 |
| 系统仪表盘 | 仅管理员：系统状态、用量排行和 Channel 健康度 |
| 服务提供者 | Provider、Channel、模型映射、健康状态、变换 |
| 令牌管理 | API 密钥、配额、模型限制、变换 |
| 日志 | 请求日志与捕获查看器 |
| 模型 | 模型价格、工具价格、上游价格同步与分组计费倍率 |
| 用户管理 | 账号、余额、订阅套餐分配与计费流水 |
| 系统设置 | 系统设置、全局变换、请求捕获开关 |

## 主仪表盘和系统仪表盘

主仪表盘只显示当前登录账号的流量、费用和健康状态。

系统仪表盘是管理员页面。它显示全系统健康状态和消耗。
消耗使用滚动时间窗口（`24h`、`3d`、`7d`、`14d`、`30d`）。
窗口截止当前时刻。窗口不在午夜重置。

## 语言

仪表盘支持 English、简体中文、繁體中文和日本語。在用户菜单中切换语言。

## 加载与恢复

概览中的各个区域独立加载。某个区域加载失败时，点击该区域的**重试**。
刷新失败时，界面保留上次的数据并显示失败提示。
无法获取的用量显示为破折号，不会显示为零。

API 基址未配置时，管理员可从 API 信息区打开系统设置。
普通用户只看到配置状态，不会看到管理员操作。

登录窗口较矮或页面放大时，可滚动页面访问完整表单。
页面无法加载设置时，先点击**重试**，再登录。
登录失败会显示本地化提示。提交失败后，请重新完成人机验证。

## 无障碍操作

界面遵循系统的减少动态效果偏好。
移动端导航按钮和弹窗关闭按钮的点击区域至少为 44×44 像素。

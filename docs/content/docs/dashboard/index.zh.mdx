## 访问仪表盘

在浏览器打开 Monoize 的监听地址，默认是 `http://localhost:8080`。release 构建在同一进程中提供仪表盘、API 和指标。

![仪表盘概览](/images/zh/dashboard.webp)

## 导航

点击 Monoize 右侧的折叠按钮，仅显示导航图标。
点击 Monoize 图标，展开侧边栏。
在 Windows 或 Linux 上按 `Ctrl+B`，在 macOS 上按 `Command+B`，切换侧边栏状态。
在移动端，点击左上角菜单按钮打开导航。
选择目标页面后，菜单自动关闭。
点击底部的账号菜单，查看余额和账号操作。

![仪表盘侧边栏](/images/zh/sidebar.webp)

## 账号与角色

- 安装后注册第一个账号。第一个注册的账号自动成为 `super_admin`。即使公开注册已关闭，此规则仍然生效。
- `super_admin` 可以管理用户、系统设置、Provider 和计费。
- `admin` 账号管理运营资源。
- `user` 账号管理自己的 API 密钥、日志和余额。

## 管理区域

| 区域 | 用途 |
| --- | --- |
| 仪表盘 | 当前登录账号的流量、费用和健康状态 |
| 系统仪表盘 | 仅管理员：系统状态、用量排行和 Channel 健康度 |
| Provider | Provider、Channel、模型映射、健康状态、变换 |
| API 密钥 | API 密钥、余额、模型限制、变换 |
| 请求日志 | 请求日志与捕获查看器 |
| 模型广场 | 当前分组可用的模型，价格已包含分组倍率 |
| 分组 | 分组与分组计费倍率 |
| 模型定价 | 模型价格、未定价模型、工具价格与上游价格同步 |
| 用户管理 | 账号、余额、订阅套餐分配与计费流水 |
| 系统设置 | 8 类系统设置，包括全局变换和请求捕获开关 |
| 账户设置 | 个人资料与密码 |

## 主仪表盘和系统仪表盘

主仪表盘只显示当前登录账号的流量、费用和健康状态。
账号没有 API 密钥或没有请求时，页面显示**开始使用**卡片，并链接到后续步骤。
在用量区选择时间窗口（`1h`、`24h`、`7d`、`30d`）。该窗口同时作用于图表和最近用量表。默认值为 `24h`，仪表盘会记住你的选择。
“今日”数值使用浏览器的本地时区。

系统仪表盘是管理员页面。它显示全系统健康状态和消耗。
消耗使用滚动时间窗口（`24h`、`7d`、`30d`），默认值为 `24h`。该窗口同时作用于健康概览和用户排行。
窗口截止当前时刻。窗口不在午夜重置。

## 系统设置

**系统设置**分为 8 类：站点、访问与会话、模型映射、全局变换、路由与可靠性、计费、隐私与抓包、协议兼容。
保存栏显示未保存的修改数量。点击**查看更改**可对比新旧值。
保存高风险修改前，Monoize 会要求确认。高风险修改会影响安全、计费或隐私。

## 语言

仪表盘支持 English、简体中文、繁體中文和日本語。在用户菜单中切换语言。

## 加载与恢复

概览中的各个区域独立加载。某个区域加载失败时，点击该区域的**重试**。
刷新失败时，界面保留上次的数据并显示失败提示。
无法获取的用量显示为破折号，不会显示为零。

API 基址未配置时，API 信息区显示当前站点地址。
管理员可从该区域打开系统设置。

登录窗口较矮或页面放大时，可滚动页面访问完整表单。
页面无法加载设置时，先点击**重试**，再登录。
登录失败会显示本地化提示。提交失败后，请重新完成人机验证。

## 无障碍操作

界面遵循系统的减少动态效果偏好。
移动端导航按钮和弹窗关闭按钮的点击区域至少为 44×44 像素。

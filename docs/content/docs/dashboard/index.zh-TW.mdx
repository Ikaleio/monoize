## 存取儀表板

在瀏覽器開啟 Monoize 的監聽位址，預設是 `http://localhost:8080`。release 建置在同一程序中提供儀表板、API 和指標。

![儀表板概覽](/images/en/dashboard.webp)

## 導覽

點選 Monoize 右側的收合按鈕，僅顯示導覽圖示。
點選 Monoize 圖示，展開側邊欄。
在 Windows 或 Linux 上按 `Ctrl+B`，在 macOS 上按 `Command+B`，切換側邊欄狀態。
在行動裝置上，點選左上角選單按鈕開啟導覽。
選取目標頁面後，選單會自動關閉。
點選底部的帳號選單，查看餘額與帳號操作。

![儀表板側邊欄](/images/en/sidebar.webp)

## 帳號與角色

- 安裝後註冊第一個帳號。第一個註冊的帳號自動成為 `super_admin`。即使公開註冊已關閉，此規則仍然生效。
- `super_admin` 可以管理使用者、系統設定、Provider 和計費。
- `admin` 帳號管理營運資源。
- `user` 帳號管理自己的 API 金鑰、日誌和餘額。

## 管理區域

| 區域 | 用途 |
| --- | --- |
| 儀表板 | 目前登入帳號的流量、費用和健康狀態 |
| 系統儀表板 | 僅管理員：系統狀態、用量排名和 Channel 健康度 |
| Provider | Provider、Channel、模型對應、健康狀態、變換 |
| API 金鑰 | API 金鑰、餘額、模型限制、變換 |
| 請求日誌 | 請求日誌與擷取檢視器 |
| 模型廣場 | 目前群組可用的模型，價格已包含群組倍率 |
| 群組 | 群組與群組計費倍率 |
| 模型定價 | 模型價格、未定價模型、工具價格與上游價格同步 |
| 使用者管理 | 帳號、餘額、訂閱方案指派與計費流水 |
| 系統設定 | 8 類系統設定，包括全域變換和請求擷取開關 |
| 帳戶設定 | 個人資料與密碼 |

## 主儀表板與系統儀表板

主儀表板只顯示目前登入帳號的流量、費用和健康狀態。
帳號沒有 API 金鑰或沒有請求時，頁面會顯示**開始使用**卡片，並連結到後續步驟。
在用量區選擇時間視窗（`1h`、`24h`、`7d`、`30d`）。該視窗同時套用於圖表和最近用量表。預設值為 `24h`，儀表板會記住你的選擇。
「今日」數值使用瀏覽器的本地時區。

系統儀表板是管理員頁面。它顯示全系統健康狀態與消耗。
消耗使用滾動時間範圍（`24h`、`7d`、`30d`），預設值為 `24h`。該範圍同時套用於健康概覽和使用者排名。
時間範圍截止目前時刻。時間範圍不在午夜重設。

## 系統設定

**系統設定**分為 8 類：網站、存取與工作階段、模型對應、全域變換、路由與可靠性、計費、隱私與抓包、協定相容。
儲存列顯示未儲存的修改數量。點擊**檢視變更**可比較新舊值。
儲存高風險修改前，Monoize 會要求確認。高風險修改會影響安全、計費或隱私。

## 語言

儀表板支援 English、简体中文、繁體中文和日本語。在使用者選單中切換語言。

## 載入與恢復

概覽中的各個區域獨立載入。某個區域載入失敗時，按一下該區域的**重試**。
重新整理失敗時，介面保留上次的資料並顯示失敗提示。
無法取得的用量顯示為破折號，不會顯示為零。

API 基底網址未設定時，API 資訊區顯示目前網站位址。
管理員可從該區域開啟系統設定。

登入視窗較矮或頁面放大時，可捲動頁面存取完整表單。
頁面無法載入設定時，先按一下**重試**，再登入。
登入失敗會顯示本地化提示。提交失敗後，請重新完成人機驗證。

## 無障礙操作

介面遵循系統的減少動態效果偏好。
行動裝置導覽按鈕和彈出視窗關閉按鈕的點選區域至少為 44×44 像素。

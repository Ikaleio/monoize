## ダッシュボードへのアクセス

ブラウザで Monoize の待ち受けアドレスを開きます。既定は `http://localhost:8080` です。release ビルドは、ダッシュボード、API、メトリクスを 1 つのプロセスで提供します。

![ダッシュボード概要](/images/en/dashboard.webp)

## アカウントとロール

- インストール後、最初のアカウントを登録します。最初に登録したアカウントが `super_admin` になります。公開登録が無効の場合でも、この規則は適用されます。
- `super_admin` はユーザー、システム設定、Provider、課金を管理できます。
- `admin` アカウントは運用リソースを管理します。
- `user` アカウントは自分の API キー、ログ、残高を管理します。

## 管理エリア

| エリア | 用途 |
| --- | --- |
| ダッシュボード | トラフィック、コスト、ヘルスの概要 |
| プロバイダー | Provider、Channel、モデル対応付け、ヘルス、変換 |
| トークン管理 | API キー、クォータ、モデル制限、変換 |
| ログ | リクエストログとキャプチャビューア |
| モデルデータベース | Models.dev から取り込んだモデルメタデータと価格 |
| ユーザー管理 | アカウント、残高、課金台帳 |
| 設定 | システム設定、グローバル変換、リクエストキャプチャの切り替え |

## 言語

ダッシュボードは English、简体中文、繁體中文、日本語に対応します。ユーザーメニューから言語を変更します。

## 概要

Monoize は Rust 製の AI API ゲートウェイです。OpenAI Responses、OpenAI Chat Completions、Anthropic Messages、埋め込み、画像形式のリクエストを受け付けます。リクエストを設定済みの上流 Channel（チャネル）へ転送し、クライアントが使用したプロトコルでレスポンスを返します。

Monoize はフィールド名ではなく、プロトコルの意味論を変換します。各リクエストを型付きの内部表現へデコードし、選択された上流プロトコルへエンコードします。レスポンスは同じ経路を逆向きにたどります。テキスト、推論、暗号化された推論、ツール呼び出し、ツール結果、画像、使用量、ストリーム境界は、変換を通してそれぞれの役割を保持します。

## 主な機能

- **プロトコル変換。** 対応する任意の下流エンドポイントから、設定済みの任意の上流タイプを呼び出せます。Monoize は Responses、Chat Completions、Messages、Gemini、画像プロトコルをストリーミング・非ストリーミングの両モードで変換します。
- **ルーティングと信頼性。** 1 つの論理モデルは複数の順序付き Provider（プロバイダー）にマッチできます。各 Provider は重み付きの Channel を持ちます。Monoize は再試行可能な失敗をリトライし、次のルートへ進み、最初のレスポンスバイト送出後はフォールバックを停止します。[ルーティングと信頼性](/ja/docs/routing)を参照してください。
- **変換（Transform）。** 33 個の組み込み変換が、Provider 単位・API キー単位・グローバルにリクエストとレスポンスを調整します。[変換](/ja/docs/transforms)を参照してください。
- **リクエストキャプチャ。** キャプチャは既定で無効です。有効にすると、各上流試行の完全なペイロードを保存します。構造化ビューアで各ホップを確認できます。[リクエストログ](/ja/docs/request-logs)を参照してください。
- **ダッシュボード。** 組み込みの Web ダッシュボードで Provider、Channel、モデル、API キー、ユーザー、課金、ログを管理します。[ダッシュボード](/ja/docs/dashboard)を参照してください。

## 対応エンドポイント

| メソッド | エンドポイント | 契約 |
| --- | --- | --- |
| `GET` | `/v1/models` | OpenAI 互換モデル一覧 |
| `POST` | `/v1/responses` | OpenAI Responses（ストリーミング / 非ストリーミング） |
| `GET` | `/v1/responses` | OpenAI Responses WebSocket トランスポート |
| `POST` | `/v1/responses/compact` | Responses コンパクション |
| `POST` | `/v1/chat/completions` | OpenAI Chat Completions |
| `POST` | `/v1/messages` | Anthropic Messages |
| `POST` | `/v1/embeddings` | 埋め込み |
| `POST` | `/v1/images/generations` | 画像生成 |
| `POST` | `/v1/images/edits` | マルチパート画像編集 |

すべての転送エンドポイントには `/api/v1/...` のエイリアスがあります。

## 上流 Channel タイプ

| タイプ | ネイティブ上流契約 |
| --- | --- |
| `responses` | OpenAI Responses 互換 |
| `chat_completion` | OpenAI Chat Completions 互換 |
| `messages` | Anthropic Messages 互換 |
| `gemini` | Google Gemini ネイティブ |
| `openai_image` | OpenAI 互換画像 API |
| `replicate` | Replicate predictions |

## 制限

- Monoize はツール定義とツール呼び出しを転送します。ツールをローカルで実行しません。
- Monoize は OpenAI Files、ベクトルストア、ローカル検索を提供しません。
- 最初の下流バイト送出後、フォールバックは終了します。Monoize は可視ストリームの途中で Provider を切り替えません。
- プロトコルファミリーをまたぐ変換は、表現可能な意味論を保持します。安全な対応先がないプロバイダー固有のネストフィールドは削除されます。
- 画像圧縮はオプトインです。`image_resolve_urls` 変換を設定しない限り、Monoize はリモート画像 URL を取得しません。

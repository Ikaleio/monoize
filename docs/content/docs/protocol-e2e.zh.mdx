---
title: 协议端到端测试
description: 在隔离容器中通过 Monoize 测试真实 CLI 与指定上游。
---

在仓库根目录运行测试。先安装 Bun，并启动兼容 Docker 的服务。
工具使用当前工作区源码构建独立镜像，包含未提交改动。
它不会部署 Monoize，也不会使用现有 Dashboard 配置。

```bash
bun e2e/cli.ts list
export BASE_URL='https://example.com/v1/chat/completions'
export API_KEY='your-upstream-key'
export MODEL='your-model'
bun e2e/cli.ts run --harness codex-responses-ws-v2,claude-messages
```

`BASE_URL` 必须包含完整端点。工具保留路径和查询参数。
标准路径后缀可推断 `responses`、`chat_completion` 或 `messages`。
使用自定义路径时，必须显式设置 `--upstream-type`。
类型冲突或 harness 不存在时，工具会在创建容器前报错。
真实上游调用会消耗上游账户额度。

构建会使用已配置的 `HTTP_PROXY`、`HTTPS_PROXY` 和 `NO_PROXY`。
本机回环代理优先使用 Docker daemon 配置的代理地址，否则转换为 `host.docker.internal`。
这些变量不会写入运行镜像。

## 选择客户端和限制

支持 `codex-responses-ws-v2`、`claude-messages`、`opencode-responses`、`opencode-chat`、`pi-responses` 和 `pi-chat`。
每个 ID 对应一个客户端及其下游协议。默认选择 `all`。
可重复传入 `--harness`，也可用逗号分隔 ID。

| 参数 | 默认值或行为 |
| --- | --- |
| `--base-url`、`--api-key`、`--model` | 覆盖 `BASE_URL`、`API_KEY`、`MODEL` |
| `--upstream-type` | 覆盖 `UPSTREAM_TYPE`；未设置时根据 URL 推断 |
| `--jobs` | `1`；增大后并行执行 |
| `--timeout` | 每项 `1800` 秒，不含镜像构建时间 |
| `--max-requests` | `100` 次生成，包含重试，不包含 WS 预热 |
| `--repo`、`--ref` | `https://github.com/Ikaleio/Monoize`、`HEAD` |
| `--task`、`--task-file` | 自定义提示词，两者互斥 |
| `--monoize-image` | 使用现成镜像，跳过 Monoize 构建 |
| `--output` | 项目内的新目录，默认位于 `e2e/.runs/` |

工具只解析一次仓库版本，所有测试项使用同一 commit。
每项使用独立容器、凭据、数据库和工作目录。
单项失败后继续其他项，不自动重跑。
中断时保留已收集的证据，并清理临时容器和卷。

## 查看结果

在输出目录查看 `report.json` 和各 harness 的事件文件。
报告分别列出协议验收与任务验收，并记录源码、镜像和客户端版本。
凭据会被脱敏。每项证据超过 128 MiB 时，该项失败。

协议验收要求工具调用、本地执行、结果回传和后续生成全部完成。
Codex 必须实际使用 WS v2，并通过 `previous_response_id` 续接。
回退到 HTTP 会使该 harness 失败。

内置任务克隆仓库、读取至少三个源码文件，并写出架构说明。
验收检查版本、执行记录、文档标题和真实存在的源码引用。
这些检查不能证明说明中的所有结论都正确。
自定义任务要求正常退出、非空最终回答，以及同样的协议验收。
自定义任务不执行仓库专用检查。

退出码：全部通过为 `0`，测试项失败为 `1`，参数或初始化错误为 `2`，中断为 `130`。
支持六种 harness 与三种上游类型。每种上游配置需分别运行。
缺少凭据或兼容模型的组合仍属于未验证。

## 检查测试工具

```bash
cd e2e
bun install --frozen-lockfile
bun run check
bun test
```

`fixture.ts` 提供确定性上游，用于开发验证。
夹具结果不能证明真实模型兼容性。

OpenCode 使用无状态 Responses 请求，并禁用标题和摘要代理。Claude 关闭可选的思考功能。
辅助 HTTP 错误保留在证据中，但不计为生成错误。

记录生成请求的 HTTP 错误或上游终止错误后，runner 结束该项，并继续执行排队中的测试项。

从仓库根目录运行容器夹具矩阵、仓库验收和中断检查：

```bash
docker build -f e2e/Dockerfile -t monoize-e2e:dev .
E2E_DOCKER_IMAGE=monoize-e2e:dev bun test e2e/docker.test.ts
```

---
title: "フィールド: 削除"
description: 設定したパスの JSON 値をリクエストまたはレスポンスから削除します。
---

## 動作

この変換は設定された extra_body パスの JSON 値を削除します。リクエストフェーズでは上流へ送るペイロードを、レスポンスフェーズではクライアントへ返すペイロードを編集します。

パスが存在しない場合、この変換は何も変更しません。

## リファレンス

| 項目 | 値 |
| --- | --- |
| タイプ ID | `field_remove` |
| フェーズ | `request`, `response` |
| スコープ | Provider |

## 使いどころ

- クライアントが送るベンダー固有フィールドを上流が拒否する。
- 特定の Provider 経由のクライアントからレスポンスフィールドを隠したい。

## 設定

| オプション | 型 | 必須 | デフォルト | 説明 |
| --- | --- | --- | --- | --- |
| `path` | string | はい | — | 削除する値の extra_body パス（ドット区切り）。例: `metadata.tags`。 |

### ルール例

```json
{
  "transform": "field_remove",
  "enabled": true,
  "phase": "request",
  "models": [
    "*"
  ],
  "config": {
    "path": "metadata"
  }
}
```

---
title: "推論: リクエスト入力から除去"
description: 上流エンコード前にリクエスト入力から推論ノードを削除します。
---

## 動作

この変換は、Monoize が上流向けにリクエストをエンコードする前に、リクエスト入力から推論ノードを削除します。`reasoning_strip_output` のリクエスト側の対になる変換です。

## リファレンス

| 項目 | 値 |
| --- | --- |
| タイプ ID | `reasoning_strip_input` |
| フェーズ | `request` |
| スコープ | Provider, API キー |

## 使いどころ

- 上流が入力内の再送された推論アイテムを拒否する。
- クライアントが推論を含む全履歴を再送する際、入力トークンコストを削減したい。

## 設定

この変換にはオプションがありません。`config` には空オブジェクトを指定します。

### ルール例

```json
{
  "transform": "reasoning_strip_input",
  "enabled": true,
  "phase": "request",
  "models": [
    "*"
  ],
  "config": {}
}
```

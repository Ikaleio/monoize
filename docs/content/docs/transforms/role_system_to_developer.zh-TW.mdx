---
title: "角色：system 轉 developer"
description: 把 system 角色的訊息改寫為 developer 角色。
---

## 行為

此變換把 system 角色的普通節點改寫為 developer 角色。它與 `role_developer_to_system` 互逆。

## 參考資訊

| 屬性 | 值 |
| --- | --- |
| 類型 ID | `role_system_to_developer` |
| 階段 | `request` |
| 範圍 | Provider, API 金鑰 |

## 適用場景

- 上游模型期望 `developer` 角色而不是 `system`，例如較新的 OpenAI 推理模型。

## 設定

此變換沒有設定項。`config` 使用空物件。

### 範例規則

```json
{
  "transform": "role_system_to_developer",
  "enabled": true,
  "phase": "request",
  "models": [
    "o*"
  ],
  "config": {}
}
```

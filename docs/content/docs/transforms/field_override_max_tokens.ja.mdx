---
title: "フィールド: 最大トークンの上書き"
description: リクエストの最大出力トークン上限を固定値に設定します。
---

## 動作

この変換はリクエストの最大出力トークン上限を設定値にします。クライアントが送った上限は置き換えられます。

## リファレンス

| 項目 | 値 |
| --- | --- |
| タイプ ID | `field_override_max_tokens` |
| フェーズ | `request` |
| スコープ | Provider |

## 使いどころ

- 上流がトークン上限の超過したリクエストを拒否する。
- クライアント設定に関係なく、特定の Provider の出力長を制限したい。

## 設定

| オプション | 型 | 必須 | デフォルト | 説明 |
| --- | --- | --- | --- | --- |
| `value` | integer | はい | — | リクエストに書き込む最大出力トークン上限。最小値は 1。 |

### ルール例

```json
{
  "transform": "field_override_max_tokens",
  "enabled": true,
  "phase": "request",
  "models": [
    "*"
  ],
  "config": {
    "value": 8192
  }
}
```

この変換は Provider スコープ専用です。出力トークン上限を変更するため、API キースコープでは使えません。

---
title: "提示詞：追加空 user 訊息"
description: 當輸入以 assistant 訊息結尾時追加一個佔位 user 訊息。
---

## 行為

當請求輸入以 assistant 節點結尾時，此變換追加一個佔位 user 文字節點。已經以 user 節點結尾的輸入原樣通過。

## 參考資訊

| 屬性 | 值 |
| --- | --- |
| 類型 ID | `prompt_append_empty_user` |
| 階段 | `request` |
| 範圍 | Provider, API 金鑰 |

## 適用場景

- 上游拒絕最後一條訊息來自 assistant 的會話。
- 用戶端向嚴格的上游發送 assistant 預填式訊息。

## 設定

| 選項 | 類型 | 必填 | 預設值 | 說明 |
| --- | --- | --- | --- | --- |
| `content` | string | 否 | `" "` | 佔位 user 訊息的文字內容。預設為一個空格。 |

### 範例規則

```json
{
  "transform": "prompt_append_empty_user",
  "enabled": true,
  "phase": "request",
  "models": [
    "*"
  ],
  "config": {}
}
```

---
title: "角色：developer 转 system"
description: 把 developer 角色的消息改写为 system 角色。
---

## 行为

此变换把 developer 角色的普通节点改写为 system 角色。它与 `role_system_to_developer` 互逆。

## 参考信息

| 属性 | 值 |
| --- | --- |
| 类型 ID | `role_developer_to_system` |
| 阶段 | `request` |
| 范围 | Provider, API 密钥 |

## 适用场景

- 上游不接受较新 OpenAI 客户端发送的 `developer` 角色。

## 配置

此变换没有配置项。`config` 使用空对象。

### 示例规则

```json
{
  "transform": "role_developer_to_system",
  "enabled": true,
  "phase": "request",
  "models": [
    "*"
  ],
  "config": {}
}
```

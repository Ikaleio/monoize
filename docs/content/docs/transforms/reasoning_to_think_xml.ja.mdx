---
title: "推論: think XML へ変換"
description: 推論内容を think タグで包んで assistant テキストに含めます。
---

## 動作

この変換は推論ノードの内容を、設定タグ（例: `<think>...</think>`）で包んだ assistant テキストに変換します。`reasoning_from_think_xml` の逆変換です。

- プレーンテキストは推論の `content`、なければ `summary` です。プレーンテキストのない推論ノードは変更しません。
- 変換された各セグメントには開始タグと終了タグが 1 つずつ付きます。
- ストリームでは、Monoize は他のノードのイベントの前とレスポンス終了の前にタグを閉じます。
- タグを閉じた後に再開した推論は、他に開いているノードがなくなるまで待ちます。その後、別のタグ付きセグメントとして出力します。後から届いた回答テキストの後になる場合があります。
- 変換されたノードの暗号化データは失われます。
- 最終出力はストリームのテキストと一致します。

## リファレンス

| 項目 | 値 |
| --- | --- |
| タイプ ID | `reasoning_to_think_xml` |
| フェーズ | `response` |
| スコープ | Provider, API キー |

## 使いどころ

- クライアントが assistant テキストのみ描画するが、推論も見せたい。
- 下流ツールがテキストから think タグを解析する。

## 設定

| オプション | 型 | 必須 | デフォルト | 説明 |
| --- | --- | --- | --- | --- |
| `tag` | string | はい | — | 推論テキストを包む XML タグ名。例: `think`。 |

### ルール例

```json
{
  "transform": "reasoning_to_think_xml",
  "enabled": true,
  "phase": "response",
  "models": [
    "*"
  ],
  "config": {
    "tag": "think"
  }
}
```

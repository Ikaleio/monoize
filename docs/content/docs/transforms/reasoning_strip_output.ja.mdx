---

## 動作

この変換はレスポンス出力とストリームイベントから推論ノードを削除します。クライアントは推論の見えない最終回答のみ受け取ります。

## リファレンス

| 項目 | 値 |
| --- | --- |
| タイプ ID | `reasoning_strip_output` |
| フェーズ | `response` |
| スコープ | Provider, API キー |

## 使いどころ

- エンドユーザーにモデルの推論を見せたくない。
- 推論アイテムを受け取るとクライアントが壊れる。

## 設定

この変換にはオプションがありません。`config` には空オブジェクトを指定します。

### ルール例

```json
{
  "transform": "reasoning_strip_output",
  "enabled": true,
  "phase": "response",
  "models": [
    "*"
  ],
  "config": {}
}
```

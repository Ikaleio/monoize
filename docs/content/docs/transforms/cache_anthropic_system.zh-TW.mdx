---
title: "自動快取：Anthropic 系統提示詞"
description: 在系統提示詞之後插入 Anthropic cache_control 快取斷點。
---

## 行為

此變換在請求的最後一個 system 或 developer 節點上插入 Anthropic ephemeral `cache_control` 快取斷點。上游隨後快取穩定的系統前綴，並在後續請求中直接讀取快取。

請求中沒有 system 或 developer 節點時，此變換不做任何修改。

## 參考資訊

| 屬性 | 值 |
| --- | --- |
| 類型 ID | `cache_anthropic_system` |
| 階段 | `request` |
| 範圍 | Provider, API 金鑰 |

## 適用場景

- 上游相容 Anthropic 協議，且快取寫入和讀取按折扣價計費。
- 用戶端在每個請求中都發送冗長且穩定的系統提示詞。

## 設定

| 選項 | 類型 | 必填 | 預設值 | 說明 |
| --- | --- | --- | --- | --- |
| `ttl` | string | 否 | `"5m"` | `5m` 或 `1h`。插入的快取斷點的有效期。`5m` 發送 `{"type": "ephemeral"}`，`1h` 額外加入 `"ttl": "1h"`。 |

1 小時快取寫入按基礎輸入價的 2 倍計費，5 分鐘快取寫入按 1.25 倍計費。

`1h` 斷點位於 `5m` 斷點之後時，Anthropic 會拒絕請求。所有 Anthropic `cache_*` 規則應使用相同的 `ttl`，或只在靠前的斷點上使用 `1h`。

Provider 規則先於 API 金鑰規則執行。後執行的規則會改寫 Monoize 已插入斷點的 TTL，因此 API 金鑰規則覆蓋 Provider 規則。用戶端自帶的 `cache_control` 始終保持不變。

### 範例規則

```json
{
  "transform": "cache_anthropic_system",
  "enabled": true,
  "phase": "request",
  "models": [
    "claude-*"
  ],
  "config": {}
}
```

與 `cache_anthropic_tool_use` 組合使用，可以在工具迴圈中同時快取會話前綴。

---
title: "推論: 暗号化ペイロードの除去"
description: プレーンテキストの推論を残したまま、暗号化された推論ペイロードを削除します。
---

## 動作

この変換はレスポンスノード、ストリームイベント、パススルー状態から暗号化された推論ペイロードを削除します。プレーンテキストの推論はそのまま残ります。

## リファレンス

| 項目 | 値 |
| --- | --- |
| タイプ ID | `reasoning_strip_encrypted` |
| フェーズ | `response` |
| スコープ | Provider, グローバル, API キー |

## 使いどころ

- クライアントが会話履歴を保存し、ペイロードを復号できない別の Provider に再送する。
- レスポンスを小さくしたく、暗号化推論の継続性が不要である。

## 設定

この変換にはオプションがありません。`config` には空オブジェクトを指定します。

### ルール例

```json
{
  "transform": "reasoning_strip_encrypted",
  "enabled": true,
  "phase": "response",
  "models": [
    "*"
  ],
  "config": {}
}
```

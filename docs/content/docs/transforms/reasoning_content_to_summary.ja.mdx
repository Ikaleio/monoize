---

## 動作

この変換はレスポンスとストリームで、プレーンテキストの推論内容を推論サマリーフィールドに移動します。サマリーフィールドのみ読むクライアントが推論を確認できるようになります。

## リファレンス

| 項目 | 値 |
| --- | --- |
| タイプ ID | `reasoning_content_to_summary` |
| フェーズ | `response` |
| スコープ | Provider, API キー |

## 使いどころ

- 上流が生の推論内容を返すが、クライアントは Responses 形式のサマリーを期待している。

## 設定

この変換にはオプションがありません。`config` には空オブジェクトを指定します。

### ルール例

```json
{
  "transform": "reasoning_content_to_summary",
  "enabled": true,
  "phase": "response",
  "models": [
    "*"
  ],
  "config": {}
}
```

---

## 動作

この変換は、対象となるツール結果コンテンツブロックに明示的な OpenAI プロンプトキャッシュブレークポイントを挿入します。明示的ブレークポイントをサポートする GPT モデルファミリーが対象です。

対象ブロックのないリクエストは変更されずに通過します。

## リファレンス

| 項目 | 値 |
| --- | --- |
| タイプ ID | `cache_openai_tool_use` |
| フェーズ | `request` |
| スコープ | Provider, グローバル, API キー |

## 使いどころ

- エージェントクライアントが明示的ブレークポイント対応の OpenAI 互換上流でツールループを実行する。
- ツールループのプレフィックスを反復のあいだキャッシュしたい。

## 設定

この変換にはオプションがありません。`config` には空オブジェクトを指定します。

### ルール例

```json
{
  "transform": "cache_openai_tool_use",
  "enabled": true,
  "phase": "request",
  "models": [
    "gpt-*"
  ],
  "config": {}
}
```

---
title: "ロール: 連続同一ロールの結合"
description: 同じロールを持つ隣接メッセージを結合します。
---

## 動作

この変換は、同じロールを持つ隣接した通常ノードを 1 つのノードに結合します。ツール結果や制御ノードをまたいで結合することはありません。

## リファレンス

| 項目 | 値 |
| --- | --- |
| タイプ ID | `role_merge_consecutive` |
| フェーズ | `request` |
| スコープ | Provider, API キー |

## 使いどころ

- 同じロールの連続する 2 つのメッセージ（例: user メッセージが 2 連続）を上流が拒否する。

## 設定

この変換にはオプションがありません。`config` には空オブジェクトを指定します。

### ルール例

```json
{
  "transform": "role_merge_consecutive",
  "enabled": true,
  "phase": "request",
  "models": [
    "*"
  ],
  "config": {}
}
```

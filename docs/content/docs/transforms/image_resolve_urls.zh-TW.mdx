---
title: "圖像：URL 解析為 base64"
description: 下載請求中的圖片 URL，並內聯為 base64 資料。
---

## 行為

此變換並行下載請求中的圖片 URL，取代為內聯 base64 資料。下載失敗或超過大小限制的節點保持不變。

沒有此變換時，Monoize 絕不抓取遠端圖片 URL。

## 參考資訊

| 屬性 | 值 |
| --- | --- |
| 類型 ID | `image_resolve_urls` |
| 階段 | `request` |
| 範圍 | Provider, API 金鑰 |

## 適用場景

- 上游拒絕 URL 圖片源，只接受內聯 base64 資料。
- 圖片 URL 指向上游無法存取的主機，例如內網。

## 設定

| 選項 | 類型 | 必填 | 預設值 | 說明 |
| --- | --- | --- | --- | --- |
| `timeout_seconds` | integer | 否 | `30` | 每次下載的逾時秒數。 |
| `max_bytes` | integer | 否 | `20971520` | 每張圖片的最大下載位元組數。預設 20 MiB。 |
| `roles` | string[] | 否 | — | 解析哪些角色的圖片 URL：`user`、`assistant`、`system`。留空解析全部。 |

### 範例規則

```json
{
  "transform": "image_resolve_urls",
  "enabled": true,
  "phase": "request",
  "models": [
    "*"
  ],
  "config": {
    "timeout_seconds": 30,
    "roles": [
      "user"
    ]
  }
}
```

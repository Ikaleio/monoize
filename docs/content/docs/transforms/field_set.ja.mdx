## 動作

この変換は設定された extra_body パスに JSON 値を書き込みます。`when_equals` を設定すると、現在の値が指定 JSON 値と等しいときのみ書き込みます。未設定の場合は常に書き込みます。

プロトコル変換が運ばないプロバイダー固有フィールドの追加や置換に使います。

## リファレンス

| 項目 | 値 |
| --- | --- |
| タイプ ID | `field_set` |
| フェーズ | `request`, `response` |
| スコープ | Provider |

## 使いどころ

- 上流がベンダー固有フィールド（サービス階層や思考スイッチなど）を必要とする。
- Provider が処理するすべてのリクエストであるフィールド値を正規化したい。

## 設定

| オプション | 型 | 必須 | デフォルト | 説明 |
| --- | --- | --- | --- | --- |
| `path` | string | はい | — | 書き込む extra_body パス（ドット区切り）。例: `service_tier`。 |
| `value` | JSON | はい | — | そのパスに書き込む JSON 値。 |
| `when_equals` | JSON | いいえ | — | 設定した場合、現在の値がこの JSON 値と等しいときのみ書き込みます。 |

### ルール例

```json
{
  "transform": "field_set",
  "enabled": true,
  "phase": "request",
  "models": [
    "gpt-*"
  ],
  "config": {
    "path": "service_tier",
    "value": "flex"
  }
}
```

---
title: "自動キャッシュ: Anthropic ツール結果"
description: エージェントループの各ツール呼び出しの前に cache_control ブレークポイントを挿入します。
---

## 動作

リクエストがツール結果を提出するとき、この変換はツール呼び出し連鎖の直前にある最新の user ノードに Anthropic の ephemeral `cache_control` ブレークポイントを挿入します。エージェントループでは、増え続ける会話プレフィックスが反復のあいだキャッシュされ続けます。

ツール結果のないリクエストは変更されずに通過します。

## リファレンス

| 項目 | 値 |
| --- | --- |
| タイプ ID | `cache_anthropic_tool_use` |
| フェーズ | `request` |
| スコープ | Provider, API キー |

## 使いどころ

- エージェントクライアントが Anthropic 互換の上流で長いツールループを実行する。
- 各反復で会話プレフィックスを全額の入力価格ではなくキャッシュから再読するようにしたい。

## 設定

この変換にはオプションがありません。`config` には空オブジェクトを指定します。

### ルール例

```json
{
  "transform": "cache_anthropic_tool_use",
  "enabled": true,
  "phase": "request",
  "models": [
    "claude-*"
  ],
  "config": {}
}
```

title: "推理：轉為 think XML"
description: 把推理內容用 think 標籤包裹後併入 assistant 文字。
---

## 行為

此變換把推理節點內容轉換為使用設定標籤包裹的 assistant 文字，例如 `<think>...</think>`。它與 `reasoning_from_think_xml` 互逆。

- 純文字取推理的 `content`，否則取 `summary`。沒有純文字的推理節點保持不變。
- 每個轉換後的片段有一個開始標籤和一個結束標籤。
- 在串流中，Monoize 在其他節點的任何事件之前以及回應結束之前關閉標籤。
- 標籤關閉後繼續出現的推理會等到沒有其他開啟的節點，然後作為單獨的帶標籤片段輸出，可能位於之後到達的回答文字之後。
- 轉換後的節點會遺失加密資料。
- 最終輸出與串流文字一致。

## 參考資訊

| 屬性 | 值 |
| --- | --- |
| 類型 ID | `reasoning_to_think_xml` |
| 階段 | `response` |
| 範圍 | Provider, API 金鑰 |

## 適用場景

- 用戶端只渲染 assistant 文字，而你仍希望推理可見。
- 下游工具從文字中解析 think 標籤。

## 設定

| 選項 | 類型 | 必填 | 預設值 | 說明 |
| --- | --- | --- | --- | --- |
| `tag` | string | 是 | — | 包裹推理文字的 XML 標籤名，例如 `think`。 |

### 範例規則

```json
{
  "transform": "reasoning_to_think_xml",
  "enabled": true,
  "phase": "response",
  "models": [
    "*"
  ],
  "config": {
    "tag": "think"
  }
}
```

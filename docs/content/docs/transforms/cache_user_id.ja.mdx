---
title: "自動キャッシュ: ユーザー識別子"
description: Monoize のユーザー名をプロバイダーのユーザーフィールドに注入し、キャッシュ親和性を高めます。
---

## 動作

この変換は Monoize のユーザー名を Anthropic の `metadata.user_id` フィールドと OpenAI の `user` フィールドに書き込みます。プロバイダーはこれらのフィールドで、同一ユーザーのリクエストを同じキャッシュシャードへルーティングします。

クライアントがすでに値を設定している場合、この変換は上書きしません。

## リファレンス

| 項目 | 値 |
| --- | --- |
| タイプ ID | `cache_user_id` |
| フェーズ | `request` |
| スコープ | Provider, API キー |

## 使いどころ

- 上流がユーザー識別子でプロンプトキャッシュをシャーディングする。
- 複数のエンドユーザーが 1 つの Monoize デプロイを共有し、キャッシュ命中率が低い。

## 設定

この変換にはオプションがありません。`config` には空オブジェクトを指定します。

### ルール例

```json
{
  "transform": "cache_user_id",
  "enabled": true,
  "phase": "request",
  "models": [
    "*"
  ],
  "config": {}
}
```

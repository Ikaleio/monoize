---
title: "推理：转为 think XML"
description: 把推理内容用 think 标签包裹后并入 assistant 文本。
---

## 行为

此变换把推理节点内容转换为使用配置标签包裹的 assistant 文本，例如 `<think>...</think>`。它与 `reasoning_from_think_xml` 互逆。

- 纯文本取推理的 `content`，否则取 `summary`。没有纯文本的推理节点保持不变。
- 每个转换后的片段有一个开始标签和一个结束标签。
- 在流中，Monoize 在其他节点的任何事件之前以及响应结束之前关闭标签。
- 标签关闭后继续出现的推理会等到没有其他打开的节点，然后作为单独的带标签片段输出，可能位于之后到达的回答文本之后。
- 转换后的节点会丢失加密数据。
- 最终输出与流式文本一致。

## 参考信息

| 属性 | 值 |
| --- | --- |
| 类型 ID | `reasoning_to_think_xml` |
| 阶段 | `response` |
| 范围 | Provider, API 密钥 |

## 适用场景

- 客户端只渲染 assistant 文本，而你仍希望推理可见。
- 下游工具从文本中解析 think 标签。

## 配置

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `tag` | string | 是 | — | 包裹推理文本的 XML 标签名，例如 `think`。 |

### 示例规则

```json
{
  "transform": "reasoning_to_think_xml",
  "enabled": true,
  "phase": "response",
  "models": [
    "*"
  ],
  "config": {
    "tag": "think"
  }
}
```

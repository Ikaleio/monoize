---
title: "プロンプト: 孤立ツール呼び出しの除去"
description: 入力内で対応するツール結果を持たないツール呼び出しを削除します。
---

## 動作

この変換は、リクエスト入力内で `call_id` に対応するツール結果がないツール呼び出しノードを削除します。完全な呼び出し-結果ペアはそのまま残ります。

## リファレンス

| 項目 | 値 |
| --- | --- |
| タイプ ID | `prompt_strip_orphaned_tool_calls` |
| フェーズ | `request` |
| スコープ | Provider, API キー |

## 使いどころ

- クライアントが履歴を切り詰め、宙に浮いたツール呼び出しが残り、厳格な上流が拒否する。
- ツール結果の欠落に関する上流エラーが発生している。

## 設定

この変換にはオプションがありません。`config` には空オブジェクトを指定します。

### ルール例

```json
{
  "transform": "prompt_strip_orphaned_tool_calls",
  "enabled": true,
  "phase": "request",
  "models": [
    "*"
  ],
  "config": {}
}
```

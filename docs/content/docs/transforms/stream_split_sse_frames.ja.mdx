---
title: "ストリーム: 長大 SSE フレームの分割"
description: 大きな SSE デルタペイロードを複数のプロトコル準拠イベントに分割します。
---

## 動作

この変換は、設定したフレーム長を超える下流 SSE デルタペイロードを、複数のプロトコル準拠イベントに分割します。可視テキストは変わらず、フレーミングのみ変わります。

## リファレンス

| 項目 | 値 |
| --- | --- |
| タイプ ID | `stream_split_sse_frames` |
| フェーズ | `response` |
| スコープ | Provider, API キー |

## 使いどころ

- クライアントやプロキシが長い SSE フレームを破棄・切り詰める。
- 上流が大きなデルタをまとめて出力し、クライアントがより滑らかな逐次描画を必要とする。

## 設定

| オプション | 型 | 必須 | デフォルト | 説明 |
| --- | --- | --- | --- | --- |
| `max_frame_length` | integer | いいえ | — | SSE フレームペイロードの最大長。制限を超えるフレームは分割されます。 |

### ルール例

```json
{
  "transform": "stream_split_sse_frames",
  "enabled": true,
  "phase": "response",
  "models": [
    "*"
  ],
  "config": {
    "max_frame_length": 4096
  }
}
```

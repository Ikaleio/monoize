---
title: "ストリーム: ストリーミングモードの強制"
description: クライアントのリクエストに関係なく、上流の stream フラグを強制します。
---

## 動作

この変換は上流リクエストの `stream` フラグを設定値にします。クライアント側のモードは維持されます。クライアントが非ストリーミングを要求し上流がストリーミングする場合、Monoize はストリームを収集して 1 つのレスポンスとして返します。

## リファレンス

| 項目 | 値 |
| --- | --- |
| タイプ ID | `stream_force` |
| フェーズ | `request` |
| スコープ | Provider |

## 使いどころ

- 長い非ストリーミングリクエストで上流がタイムアウトするが、ストリーミングでは動作する。
- 上流が 1 つのモードしかサポートしない。

## 設定

| オプション | 型 | 必須 | デフォルト | 説明 |
| --- | --- | --- | --- | --- |
| `enabled` | boolean | はい | — | 上流リクエストに強制する stream フラグの値。 |

### ルール例

```json
{
  "transform": "stream_force",
  "enabled": true,
  "phase": "request",
  "models": [
    "*"
  ],
  "config": {
    "enabled": true
  }
}
```

この変換はリクエスト実行モードを変えるため、Provider スコープ専用です。
